# Homework core notes

- Image size uses binary kilobytes: 600 KB equals 600 × 1024 bytes.
- Submission lateness is measured as whole calendar days between the due date and submission date; early submissions have no penalty.
- Missing marks contribute zero to their criterion. Provided marks must be within that criterion's score range.
- The Android compressor returns the final JPEG at the first quality step within the byte limit, or the final quality-step result when that limit cannot be reached.
