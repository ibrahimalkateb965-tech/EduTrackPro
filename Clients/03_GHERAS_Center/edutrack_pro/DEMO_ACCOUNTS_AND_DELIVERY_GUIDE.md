## 2. مسارات الاختبار الميداني الموصى بها لإدارة المركز (<bdi>Field Testing Walkthrough</bdi>)

### 🔹 المسار 1: اختبار تدفق تقييم أداء المعلمين (<bdi>KPIs Loop</bdi>)
1. **في لوحة تحكم الويب (<bdi>Web Dashboard</bdi>):**
   * التوجه إلى تبويب **"الموظفون والكادر"** ➔ اختيار تبويب **"📊 مؤشرات تقييم الأداء"**.
   * تظهر شاشة مقارنة فورية لأداء كافة المعلمين، موضحة درجات المعايير الأربعة:
     * التفاعل داخل القاعة (<bdi>Interaction</bdi> / 10).
     * التواصل مع أولياء الأمور (<bdi>Guardian Communication</bdi> / 10).
     * الأخلاقيات والانضباط الإداري (<bdi>Discipline & Ethics</bdi> / 10).
     * الالتزام بالخطط التعليمية وإتقان المنهج (<bdi>Curriculum</bdi> / 10).
   * الضغط على زر **"📊 تقييم / تعديل"** لأي معلم لإضافة تقييم جديد مع التوجيهات وملاحظات التحسين.
2. **في تطبيق أندرويد المعلم (<bdi>Teacher App</bdi>):**
   * تسجيل الدخول بحساب المعلم التجريبي (<bdi>`teacher.demo`</bdi> / <bdi>`Password123!`</bdi>).
   * في أعلى الشاشة الرئيسية، تظهر بطاقة التقييم الأسبوعية الشفافة بتفاصيل الدرجات، التقدير ("ممتاز")، وملاحظات المشرفة وخطة التطوير الموجهة له.

---

### 🔹 المسار 2: اختبار التسكين الجماعي للطلاب في القاعات (<bdi>Bulk Enrollment</bdi>)
1. التوجه في لوحة الويب إلى شاشة **"القاعات والفصول"**.
2. الضغط على زر **"👥 تسكين ونقل الطلاب"** أمام القاعة المطلوبة (مثل قاعة الفاروق).
3. تفتح نافذة التسكين الجماعي المزودة بفلاتر سريعة:
   * تصفية الطلاب غير المسكنين في أي قاعة (<bdi>Unassigned Only</bdi>).
   * تصفية المجموعات (صباح / مساء / إنجليزي / قدرات).
   * تصفية الجنس (بنين / بنات).
4. تحديد الطلاب عبر خانات الاختيار (<bdi>Checkboxes</bdi>) والضغط على **"تسكين الطلاب المحددين"**.
5. يُحدث النظام عداد إشغال القاعة لحظياً دون الحاجة لإعادة تحميل الصفحة.

---

### 🔹 المسار 3: اختبار تسجيل الطالب والدفعة المبدئية الآلية (<bdi>Instant Registration Fee</bdi>)
1. في لوحة الويب، الدخول إلى **"شؤون الطلاب"** ➔ **"➕ إضافة طالب جديد"**.
2. تعبئة البيانات الأساسية للطالب واختيار المسار التعليمي (مثل: مسار القدرات العامة واللفظية).
3. في قسم **"الرسوم والتسجيل المالي الفوري"**:
   * اختيار خطة الرسوم (مثلاً: خطة الفصل الأول).
   * إدخال رسوم التسجيل (مثلاً: <bdi>200</bdi> ر.س).
   * إدخال الدفعة الأولى المستلمة (مثلاً: <bdi>500</bdi> ر.س) وطريقة الدفع (مدى / كاش).
4. بمجرد الحفظ، يقوم النظام تلقائياً بـ:
   * إنشاء ملف الطالب وتعيين المسار والقاعة.
   * تسجيل سند قبض مالي رسمي برقم متسلسل آلي في قسم المالية.
   * خصم المبلغ فورياً من ذمة الطالب وعرض الرصيد المتبقي بدقة متناهية.

---

### 🔹 المسار 4: اختبار شاشة ولي الأمر وتنبيهات الأقساط والسلوك
1. فتح تطبيق الأندرويد وتسجيل الدخول بحساب ولي الأمر (<bdi>`guardian.demo`</bdi> / <bdi>`Password123!`</bdi>).
2. استعراض بطاقة **"الرسوم والأقساط"**:
   * يظهر الملخص المالي: المجموع المطلوب (<bdi>1,500</bdi> ر.س)، المسدد (<bdi>500</bdi> ر.س)، والمتبقي (<bdi>1,000</bdi> ر.س).
   * يظهر جدول الأقساط بمواعيد الاستحقاق القادمة وحالة كل قسط (مسدد / مستحق).
3. استعراض سجل الحضور والتقييمات والواجبات اليومية.

---

### 🔹 المسار 5: اختبار العزل المالي التام لحساب المشرفة (<bdi>Supervisor RBAC Blackout</bdi>)
1. تسجيل الدخول بحساب المشرفة.
2. المشرفة تملك كامل الصلاحيات التشغيلية (تقييم المعلمين، رصد غياب الطلاب، تسجيل الملاحظات السلوكية، وإرسال تنبيهات واتساب).
3. محاولة الدخول إلى أي شاشة أو مسار مالي (سندات، مدفوعات، خزائن، بنوك، مسير رواتب) تُرد فورياً بحظر صريح ومحكم (<bdi>403 Forbidden</bdi>)، والتقارير اليومية تُصفر حقول المبالغ المالية تلقائياً.

## 3. تعليمات تفعيل الهجرات على خادم <bdi>PostgreSQL</bdi>

لتطبيق الهجرات البرمجية والحسابات التجريبية على خادم المنظومة، يتم تشغيل الأوامر التالية بالترتيب:

```bash
# 1. تطبيق هجرة التوسعة المؤسسية (الأقسام، التقييمات، السلوك، وجدول القاعات)
psql "$DATABASE_URL" -f Clients/03_GHERAS_Center/edutrack_pro/db/postgres/012_enterprise_expansion.sql

# 2. تطبيق هجرة الحسابات التجريبية الثلاثة
psql "$DATABASE_URL" -f Clients/03_GHERAS_Center/edutrack_pro/db/postgres/013_demo_accounts_seed.sql
```

أو عبر تشغيل سكربت بايثون المخصص:
```bash
python Clients/03_GHERAS_Center/edutrack_pro/server/scripts/seed_demo_accounts.py
```

## 4. معايير الجودة والمطابقة المعتمدة
* **معيار الأرقام القياسي (<bdi>Rule 50</bdi>):** استخدام الأرقام الإنجليزية <bdi>0-9</bdi> حصراً في كافة السندات، الحسابات، الأقساط، والتقارير.
* **الأمان والحوكمة (<bdi>RBAC Security</bdi>):** تجزئة كلمات المرور عبر خوارزمية <bdi>Argon2id</bdi> فائقة الأمان.
* **الاستقرار وقابلية التوسع:** دعم كامل لتوسيع وإضافة مسارات تعليمية وأقسام جديدة دون الحاجة لإعادة كتابة الأكواد.
